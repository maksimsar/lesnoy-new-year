# Лесной — новогодние афиши

React + Vite. Пять переключаемых афиш, мобильная версия, просмотр крупным планом, сохранение PNG, печать выбранной афиши на A4 через браузер (можно выбрать «Сохранить как PDF»).

## Запуск

```sh
npm ci
npm run dev
```

## Сборка

```sh
npm run build
npm run preview
```

Статический сайт находится в `dist/`. Серверная часть не требуется. Все изображения и шрифты включены в проект.

Тексты и телефоны: `src/main.jsx`. Оформление пяти вариантов: `src/style.css`. Шрифты: `src/fonts.css`.

Исходные условия: 6 000 ₽ за гостя для сборных коллективов с программой «Лесного»; 5 000 ₽ для компаний от 60 человек со своей программой. Свой алкоголь в любом количестве, без пробкового сбора. Даты и дополнительные услуги не придуманы.

Логотип взят из предоставленного пользователем макета. Новогодний натюрморт создан встроенным ImageGen. Краткое описание промпта: editorial photographic Soviet New Year still life, antique red and silver glass ornaments, natural fir, tangerines, vinyl record and champagne coupe on a dark forest-green background; warm film light, no text or logos. Изображение является декоративным натюрмортом, а не фотографией банкетного комплекса.

## GitHub Pages

Сайт публикуется автоматически из ветки `main` через GitHub Actions. В настройках репозитория Pages → Source выбран GitHub Actions. Относительные пути позволяют работать внутри каталога репозитория. Посетителям не нужен аккаунт: они могут выбрать любую афишу и нажать «Скачать афишу».

Во всех пяти вариантах используется изображение оригинального логотипа пользователя; название не набирается шрифтом. В CSS скрыты только внешние поля, размеры печатного листа и контактная часть исходного файла.
